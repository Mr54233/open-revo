支持 Ctrl / Alt / Shift / Win 修饰键 + 字母/数字/F1-F24 等。Win 组合键若录制失败可手动输入；纯单键（无修饰键）会拦截正常打字，慎用。
宿主与其他插件的快捷键 只读 · 避免组合键冲突
宿主当前没有注册其他快捷键。
持久化说明：预置键随 OpenRevo 启动自动生效；自定义键保存在本机，打开本页面时自动恢复注册（宿主重启后首次触发前需打开一次本页）；要彻底开机自生效，点右上角「导出固化」把 JSON 粘贴进本插件 manifest.json 的 shortcuts 数组。
系统键覆写：宿主内置快捷键（Ctrl+Shift+F/M/R）可通过「✎ 覆写」改键——以相同 ID 顶替注册表条目；重启后回到宿主原始值，打开本页自动重新覆写。
已知限制：摄像头 / 麦克风 / 防休眠 / 显卡直连 / 电池限额暂无宿主快捷键动作（列表中已灰显）；同一组合键冲突时，仅最先注册的一条生效。
